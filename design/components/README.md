# 共用组件规格 v0.1

所有组件引用 [tokens](../tokens/tokens.json)，产品状态遵循 [UX.md](../../docs/UX.md)。以下是实现约束，不是已完成的组件代码。

## Button / IconButton

变体 primary（蓝底白字）、secondary（蓝字描边）、tertiary（文字）、danger（默认红字；确认层最终破坏性操作可红底白字）。同一任务区域只有一个主要动作。高度至少 48，左右内边距 16，圆角 control；图标 20，图文间距 8。

状态 default/hover/pressed/focus/disabled/loading。加载中保留宽度，显示“正在连接”等具体文案，禁止重复执行并保留焦点；Web aria-busy 配合单次状态播报。disabled 必须在邻近位置解释不可用原因；不能用禁用态替代无权限说明。图标按钮必须有可读名称，工具提示不是唯一标签。

示例：使用工作卡发送、复制验证码、刷新状态。未知发送结果时蓝色主操作为“刷新状态”，不自动变为重发。确认重发后才创建新命令。

## Field / TextArea / PasswordField

结构为持久 label → 输入框 → helper/error。label 与控件绑定，placeholder 只作示例。高度至少 48、内边距 12、圆角 control，正文 16；多行框最小 128 可增长。

状态 empty/filled/focused/invalid/disabled/readOnly。错误文本替代普通 helper 或在其后紧邻显示，不仅变红；表单提交聚焦首个错误字段。只读仍可选择复制。登录用户名和密码支持自动填充，不禁止粘贴。眼睛按钮有“显示/隐藏密码”标签；首次渲染不自动弹出手机键盘。

发送表单校验失败不丢正文，输入国际号码时区号不重复。SIM 或号码变化后仍保留正文，但最终提交使用可见字段。按下 Enter 在正文中换行，不默默发送。

## SimTabs / ReadFilter

SimTabs 以名称识别卡，选中使用 primary 文字、3px 下划线；底部细轨道，最小高度 48。连接或卡状态作为独立文本，不能把选中蓝色误作在线。接收列表允许“全部”，发件选择必须且只能选一张真实卡。

单卡用静态卡名可替代 tab；多卡横向滚动并保留当前项可见，卡名过长用省略并提供完整可访问名称。卡名重复时附设备/卡槽。离线项仍能选来读历史，不能一律 disabled。

Web 真正切换面板时使用 tablist/tab/tabpanel，方向键移动焦点、Enter/Space 激活（手动激活避免焦点移动触发查询）；Android 暴露单选语义。ReadFilter 的“全部/未读”是范围内筛选，使用独立单选组，不嵌入另一个 tablist。两者状态分别持久到当前路由。

切卡不改变现有草稿的归属，也不自动标记另一张卡的消息已读。

## ConversationRow / MessageBubble / CodeBlock

会话行包含发件人、摘要、时间、必要 SIM 标签及未读状态。行内边距上下 16，左右 pageMobile，分割线 borderSubtle，头像可选 36；同一列表风格一致。默认白底，选中 surfaceSelected；选中与未读为不同状态。

Web 行的打开入口与复制按钮为相邻可聚焦动作，不能将 button 嵌进 button/link。复制不触发打开会话。摘要最多两行，详情必须保留完整原文；数字可使用等宽/表格数字但不缩小正文。

消息气泡 incomingBubble/outgoingBubble，圆角 bubble，内边距 12–16；最大正文宽 560，同时不超过可用宽度。发送时间和结果在气泡下，用 meta 和文字表达。链接由用户明确点击才打开，正文按文本呈现，不注入 HTML。

CodeBlock 为验证码候选 + 复制动作，code 字体，不截断真实码；多个候选各有上下文与按钮。成功 toast “已复制”，失败给出手动选择路径。不能显示自创的有效期或保证验证码正确。

## StatusSummary / StatusLabel

摘要面板可用语义浅色背景、16px 内边距和 statusPanel 圆角；结构 icon + title + body + 可选 action。同一区域优先展示最高影响问题，其他问题在详情列出，不堆叠多个巨型卡片。

| 语义 | 颜色 | 例子与证据 |
| --- | --- | --- |
| neutral | textSecondary/surfaceSubtle | 未检查、等待下一步 |
| working | primary/surfaceSelected | 正在同步；只在实际任务进行时显示 |
| success | successText/successSurface | 对应事件确已确认；不从在线推断短信可用 |
| attention | warningText/warningSurface | 设备离线、结果未确认、需手动检查 |
| error | dangerText/dangerSurface | 明确请求失败、权限缺失导致功能阻塞 |

在线、权限、蜂窝状态、同步进度分别表达。未知值写“未知”，不填 0。Web 普通更新使用 polite 状态播报；需要立刻处理的错误才 alert，不能每次轮询打断读屏。

## DeliveryTimeline

按实际事件显示时间、阶段、证据来源；成功节点不代表整个命令成功。缺失节点用等待/未确认，不虚构时间。系统发送成功与送达报告分别显示。所有阶段继承领域状态，不通过前端超时把未知转换成失败。

查询不发短信。尚未领取时取消是条件操作；已经领取不能承诺取消。部分分段发送显示明细，不提供一键整条自动重发。超时刷新按原命令标识核对，保留幂等语义。

## SettingsRow / Toggle / SessionRow

设置行最小 56，双行至少 72，大字号自适应；图标 24，正文与值可换行。只有能导航的行显示 chevron；只读电量、最后尝试等不能伪装链接。行点击不与内部开关产生双次操作。

开关表达已提交的开/关值；请求中禁用重复切换，失败回滚并说明。首次配置表单中的开关可表达待保存草稿，但明确保存前不生效。通知开关关掉不禁用收件箱；关闭 SIM 同步不关闭实体卡。

SessionRow 区分此会话/其他会话，用户命名、最近使用、显式退出动作；不宣称精确设备指纹。撤销成功才移除。当前会话可直接改名，批量退出保留当前，凭证共享可能影响关联窗口的说明在确认层呈现。

## WizardStep / PermissionItem / VerificationProgress

阶段固定为连接、短信、设备、验证；显示“步骤 n / 4”，子页面不冒充多一个阶段。首次配置不展示日常底部导航；返回保留输入，稍后继续保存非敏感进度并显示未完成状态。

每次只突出一个当前权限操作。系统页面返回后重读状态，已授予不重复请求；拒绝提供说明与再次处理入口，不循环弹框。手动检查明确标为人工确认。

验证按 SIM 和测试会话隔离，手机接收与服务器确认分别显示。成功范围精确到本次收件/同步，不自动代表发件、通知或后台稳定。未验证允许稍后处理，但不得显示全部成功。

## Dialog / Toast / EmptyState

确认层只用于确有后果的动作，如撤销、换服务器、可能重复发送；正常读短信、复制、发送不增加无意义确认。Web 限定焦点、可 Escape 关闭取消、关闭后回到触发控件；移动端适配安全区，Android 遵守系统返回。只有确认才执行，点击遮罩取消。

Toast 只用于非关键短反馈如“已复制”；错误和未知发送结果不能只显示一次 toast 后消失。状态改变不自动移动输入焦点；减少动画时去除过渡，仍保留可读反馈。

空态区分：无设备→添加设备；无短信→接收测试；无未读→查看全部；无匹配卡内容→切卡。网络故障保留已加载内容并显示连接问题，不伪装为空。认证恢复阶段不展示短信正文，不先闪登录页。

## Navigation / ResponsiveShell

PWA 顶层短信/设备/设置；Android 顶层运行/短信/设置。详情、向导和登录页使用对应返回/任务入口，不机械复制底部导航。桌面 PWA 侧栏旁为会话列表和详情，宽度按 tokens 建议值并验证内容适配。

主内容不得被固定导航或键盘遮住；使用平台安全区。桌面列表和详情独立滚动，面板切换保留草稿上下文，空选中不自动打开一条消息。所有控件遵守键盘、读屏、文字放大及触控目标要求。
