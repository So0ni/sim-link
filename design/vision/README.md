本轮生成提示摘要：三张均参考已保存 Android 运行首页，逻辑画幅 390×844，中文，白蓝配色，单屏无设备外框，正文 15–16px，触控目标 48dp，使用对齐、留白、细分隔线，避免嵌套卡片。

- 连接：扫码主操作，地址手输备用，明确服务器确认，初始未检测状态，不提前申请短信权限。
- 短信能力：角色为当前操作，按实际状态检查短信权限，本机通知可稍后，保留向导进度。
- 断线恢复：琥珀色错误摘要、蓝色重试、持久队列数量与最后同步时间、精简诊断；不把暂时超时误判为需要重新配对。

生成图中的细微图标、重复状态文案和只读行箭头不作为最终组件规范；后续以组件与状态规格统一。
