# Web Push 新短信通知

> 公开记录已省略私人部署地址；验证范围和结果保持原记录。

2026-09-29 首版实现；范围为新短信、此浏览器安装实例，暂不包含 Telegram、设备失联或正文通知。依据用户最新决定，通知包含发件人，不显示短信正文。真实 iPhone 系统通知验收仍待完成。

## 使用与边界

- PWA 更新后，在「设置 → 此设备通知」点击「开启通知」，主动授权；默认关闭。每个浏览器/安装实例分别开启。
- iPhone 从 Safari 添加到主屏幕后，在主屏幕应用内操作。能力不足或权限关闭时展示恢复说明，不自动反复请求权限。
- 开启后可发送虚构测试通知。页面的“推送服务已接收”仅说明推送服务受理，不等于系统已显示或用户已读。
- 新短信提醒显示发件人；点击打开原设备、原 SIM、原发件人的会话。需要登录时保留 hash 路由，登录后继续访问。只有实际可见详情触发既有阅读状态逻辑。
- 关闭通知仍可读短信。服务端删除该订阅及待投递任务；退出、撤销或会话到期停止关联投递。重新登录后需明确开启，不自动重新绑定旧订阅。
- 已被推送服务接受或已显示的通知无法撤回。Worker 在显示发件人前检查当前会话；401 或不同会话不显示，网络不可用时仅显示无发件人通用提示，点击返回收件箱。
- 短信接收时间距服务器超过一小时的补传不提醒；不回溯订阅前历史。每个订阅、消息最多创建一项任务。

## 存储与投递

SQLite v7 增量迁移保留现有短信、阅读状态、设备及命令。VAPID 密钥首次启动生成并保存在同一数据库；不需要额外环境变量，不能在升级时重建密钥。备份包含密钥、浏览器 endpoint 和订阅密钥，按敏感凭证保护。

短信入库事务中写入通知 outbox；设备只等待本地事务提交，不等待外部推送。每 5 秒处理最多 20 项，单进程串行投递；每项网络超时 10 秒。保存尝试次数、最近尝试时间和结果（不保存外部错误正文）。网络错误、429、5xx 按 30 秒起指数退避、最高 15 分钟，最多 6 次，任务最多保留一小时投递窗口。404/410 删除失效订阅；其他明确错误停止自动重试，可在设置中发送测试通知。

进程崩溃后任务保留并重试；服务端受理但本地尚未记账时可能重复发送，使用稳定 notification tag 合并替换同消息提醒，不宣称 exactly-once。完成/失败/过期记录在 7 天后清理；短信保留规则不变。

endpoint 仅接受 HTTPS 默认端口、无用户信息/fragment，并限制为 FCM、Mozilla、Apple、Windows 的已知推送域名；不跟随任意用户提供的 HTTP 地址。新浏览器供应商需评估后扩展服务端白名单。通知数据使用标准 Web Push 加密，VAPID 私钥只在服务端；不记录 endpoint/密钥/短信正文。

## 接口

均为管理员网页会话接口；写操作校验 Origin 与 CSRF。Android 收件协议不变，已有 APK 不需要升级。

- `GET /api/v1/push`：VAPID 公钥、当前会话订阅 ID 及各自最近投递状态；不返回 endpoint 或订阅私钥。
- `POST /api/v1/push/lookup`，`{endpoint}`：仅查询当前会话绑定 ID，无匹配为 null。
- `POST /api/v1/push/subscriptions`，`{endpoint,keys:{p256dh,auth}}`：校验并绑定当前安装；相同订阅幂等，显式重新绑定清除旧会话任务。每会话每分钟 20 次，服务器最多 100 个订阅。
- `DELETE /api/v1/push/subscriptions/:id`：仅删除当前会话拥有的订阅。
- `POST /api/v1/push/subscriptions/:id/test`：排队测试通知，返回 `{queued:true}`；每会话每分钟最多 3 次。

状态：`pending`、`accepted`、`failed`、`expired`。`accepted` 不代表设备显示或用户已读。

## 验证

自动化覆盖：入库/outbox 事务与回滚、事件幂等、旧补传抑制、发件人且无正文、会话/CSRF/endpoint 校验、跨会话归属、退避/过期/失效订阅、退出清理、v6 迁移及密钥/任务重启持久化；Worker 覆盖会话校验、离线隐私回退和安全深链。

真实设备待验收：开启系统权限 → 发送测试通知 → 将 PWA 切到后台/锁屏 → 新虚构短信触发通知并显示发件人 → 点击回到对应会话 → 关闭/退出后不再接收新通知。自动化 mock 和浏览器页面验收不代替此项。

实现参考：[PushManager.subscribe](https://developer.mozilla.org/en-US/docs/Web/API/PushManager/subscribe)、[web-push](https://github.com/web-push-libs/web-push)。
