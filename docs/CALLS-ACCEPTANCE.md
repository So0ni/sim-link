# 来电同步首版验收

日期：2026-10-02（Asia/Singapore）。代码 0.5.0-calls/code14；Android 本地 v6，后端 v12。已部署正式与测试环境，并覆盖安装真机。

## 环境与证据范围

Android 模拟器 emulator-5554 / sdk_gphone16k_arm64 / Android 17；独立 QA 应用包名 dev.simlink.gateway.callsqa，使用临时 Gradle init script 构建，不修改正式 applicationId，不覆盖原应用/配对。本地隔离后端和 SQLite；adb reverse 转发到本机。所有号码为 202-555-01xx 虚构号码，短信为明确虚构文本。

通过 adb uiautomator 读取控件、input tap 操作、screencap 检查界面；没有使用 pm grant 或 install -g 授权。系统电话输入使用 emulator gsm call/cancel，未发生真实蜂窝通信。部分调度通过 cmd jobscheduler run -f 加速，不冒充自然 Doze/长时后台验收。临时数据库、配对凭证、日志、截图留在本机临时目录，不提交。

## 已验证

- 正常系统通话记录授权弹窗；先拒绝、再次主动授权恢复；电话状态权限独立正常授权。
- 开关默认关闭，授权后显式启用，状态页沿用白蓝卡片、原生按钮和设置层级。
- 新未接来电从系统通话记录采集、落盘、上传到隔离后端，号码与未接类型一致。
- 关闭期间产生的模拟电话在重新启用后未补采；重新启用后的已接来电正常上传为 incoming，系统时长 63 秒，不误判为未接。
- 同一号码两次电话形成两条记录；重复扫描不重复上传。
- 停止隔离后端时，新来电保留 pending，服务端原有记录数量不变；重启后补传成功。
- 撤销 READ_CALL_LOG 后，服务端报告 permission=false；授权 RECEIVE_SMS 后的新虚构短信仍正常上传，来电权限失败未阻塞短信。
- Web 手机宽度列表、自动查看标记（结果仍为 missed）、号码复制、tel 打开当前系统拨号器并预填号码（未点击拨出）。
- Web 宽屏布局通过调整模拟器窗口/密度验证列表与详情双栏；验证后恢复原尺寸和密度。
- API 鉴权隔离、CSRF、事件重放/冲突、未来时间、分页、撤销凭证、状态上报、新未接私密通知与旧记录抑制由自动化测试覆盖。
- Web stale poll 不撤销已查看、来电原始时间排序、安全拨号链接由自动化测试覆盖。
