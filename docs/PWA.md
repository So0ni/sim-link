# 安装型 PWA · 2026-09-29

> 公开记录已省略私人部署地址；验证范围和结果保持原记录。

实现：生产构建带manifest（稳定id `/`、standalone、根scope、无敏感参数的启动URL）、192/512 PNG（含maskable用途）、180px Apple图标。设置页展示安装说明、浏览器支持时的安装按钮和手动检查更新。源码与演示构建不注册Service Worker。

## 缓存与升级

- Vite构建插件根据静态文件及Worker源码计算版本，生成 `/sw.js`。资源列表只包含index.html、当轮JS/CSS、清单和图标。
- 安装时匿名GET预缓存白名单；任一失败撤销新缓存，不强制激活、不替换已用版本。没有运行时追加缓存。
- 私有API、其他源、查询字符串、非GET、发现接口和健康检查都不拦截，不持久保存Cookie/CSRF/短信响应。服务端no-store继续保留；Cache Storage中的静态外壳来自显式预缓存。
- 受控根页面导航使用对应版本外壳，hash路由不作为缓存键。断网重开能加载外壳，必须联网确认会话，然后先恢复同一会话的本地视图并后台更新；已开页面可继续显示已加载短信。
- 新Worker等待；用户接受后skipWaiting，controllerchange让已有受控页面刷新。首次激活不刷新、不误报新版本。也允许浏览器在所有旧页面关闭后正常激活。旧simlink-shell缓存在激活时清理，不清理其他缓存。
- 每次打开会检查脚本，回前台/恢复网络触发更新检查（至少间隔60秒）；也可在设置页检查。更新失败不影响收件。仍使用HttpOnly持久Cookie，无离线登录替代逻辑。

## iPhone 真机验收步骤

1. Safari打开开发站点并登录，进入设置确认“离线界面已准备好”。
2. 分享 → 添加到主屏幕；若有“作为网页App打开”则启用。检查图标和名称。
3. 从主屏幕打开，若首次要求登录则正常登录；关闭窗口后重开、锁屏再回来，确认不反复要求密码。
4. 开启飞行模式后重开，确认显示离线外壳/连接提示而不是假登录成功或旧短信缓存。恢复网络后应恢复会话，必要时点重试。
5. 后续发版检查升级提示，点稍后不跳走，点更新后恢复页面与登录。

记录iOS版本和实际结果，不在截图中包含真实短信、验证码或凭证。主屏幕应用可能与浏览器使用独立数据环境，首次重新登录不等同于持久会话失败。

## 视图快照与静默刷新（2026-09-29）

按用户新要求，增加独立于Service Worker的视图缓存：localStorage按网页会话ID隔离，包含近期最多500条短信、设备/SIM、最近200条发件记录及刷新时间。快照最长24小时，序列化限制200万字符，存储不可用/超限不阻断内存使用与网络访问。无Cookie、CSRF、配对码或未提交草稿。重新打开仍先通过服务端确认会话，再同步恢复快照；消息/阅读游标从0补齐并按版本合并，避免截断快照导致旧记录永久缺失。网络错误保留快照，401或成功退出清除；同源其他标签通过storage清理事件一同退出。切换页面使用内存快照，恢复后后台校准。

自动刷新不改变按钮、列表标题或已加载状态；成功后才更新刷新时间。手动刷新仅对应圆形箭头按钮旋转和禁用，重复点击不会并发请求；失败仍正常显示错误。短信、设备、设置和发件页使用统一手机品牌标题区；号码头像使用末两位，文字发件人用首个字符。移除轮询频率说明和升级Android提示。
