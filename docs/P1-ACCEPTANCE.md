# P1 收件同步验收

更新：2026-09-29。状态：核心收件闭环通过，可靠性验收仍有待测项。

环境：小米 24115RA8EC（amethyst）、Android 16、Gateway 0.2.3-p1；局域网 HTTP Debug；单容器 Web/API、SQLite v2。以下结果不代表所有 Android 14+ 机型或 HTTPS Release 已验收。仅记录结果，不保存真实号码、短信正文和凭证。

## 公网服务 + 模拟器接收验证（2026-09-29）

使用 `emulator-5554`（sdk_gphone16k_arm64，系统 release 17）与 Gateway 0.4.0-p2/code9，通过正常配对流程连接 `https://sim.example.com`，设备名 `SIMLink-Emulator-QA`。HTTPS系统证书验证通过，接收短信与读取SIM权限已授予；未启用远程发送。

通过模拟器控制台注入一条虚构短信，标识 `20260929-RX01`，发送方使用虚构号码 +12025550123。Android 状态从待同步1变为待同步0、已同步1，并显示上传已获服务器确认；线上Web前台轮询自动显示1个会话、未读1。打开详情后正文及T-Mobile/卡槽1一致，自动标读；刷新后登录、正文与已读状态恢复。旧本地短信未迁移。

测试设备保持配对，线上保留此条标明TEST ONLY的记录供查看。没有使用真实SIM，没有发送收费短信；此结果不涵盖运营商接收、长期后台或真机省电行为。
