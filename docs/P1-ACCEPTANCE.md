# P1 收件同步验收

更新：2026-09-29。状态：核心收件闭环通过，可靠性验收仍有待测项。

环境：小米 24115RA8EC（amethyst）、Android 16、Gateway 0.2.3-p1；局域网 HTTP Debug；单容器 Web/API、SQLite v2。以下结果不代表所有 Android 14+ 机型或 HTTPS Release 已验收。仅记录结果，不保存真实号码、短信正文和凭证。

## 真机证据

| 场景 | 结果与依据 |
| --- | --- |
| 普通短信端到端 | 通过。用户确认 Android 与 Web 都收到一条，正文完整。 |
| 断网恢复补传 | 通过。按关闭 Wi-Fi/移动数据但保留蜂窝短信的步骤测试，用户确认恢复网络后 Web 只出现一条、正文完整。 |
| 心跳与在线显示 | 强制任务触发已验证；用户另确认锁屏状态下心跳正常工作。未记录观察时长与间隔，不据此承诺精确周期。 |
| 短时锁屏收件同步 | 通过。用户确认锁屏状态下同步正常工作。 |
| 重启并首次解锁后恢复 | 通过。用户按上一项重启恢复测试反馈“重启也完全正常”。 |

- 后端 13 项测试通过：认证、配对凭证隔离、幂等入库、心跳、撤销、v1 → v2 迁移与历史保留。
- Web 13 项测试、类型检查、生产构建通过；模板部署兼容测试 4 项通过。浏览器虚构短信验证前台自动刷新。
- Android 23 项 JVM 测试、Debug/Release 构建、Debug Lint 通过；Release 为未签名产物，不是正式发布。
- 独立 Compose 检查通过：打包 Web、登录、配对、心跳、收件、容器重建、会话/短信持久化、重复上传去重、解绑后条目删除且历史保留、旧凭证失效。仅清理其独立测试卷。
