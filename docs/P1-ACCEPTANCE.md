## 后续验收顺序

2026-09-30：Android 0.4.1-p2/code10 新增短信触发加急任务、普通任务回退和阶段时间日志。以下专项均待真机验证，不沿用旧版短时锁屏通过结论：

- 亮屏、短时锁屏、长时间锁屏/Doze 分别观察接收、入库、任务启动、服务器确认时间；只采集 `SIMLinkSync` 固定阶段日志，不保存短信内容。
- 连续收件及任务即将完成时的新收件不遗漏；服务器每条只出现一次。
- 断网接收后恢复联网，队列最终得到 ACK；加急配额不足时普通任务/周期补偿仍有效。
- 如果系统短信已收到而 Gateway 无接收阶段，单独检查厂商广播拒绝及单应用省电设置，不能归因为上传调度。
