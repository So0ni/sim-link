# 数据与隐私

SIMLink 是自托管软件。部署者管理服务器和数据；当前没有项目运营的公共短信后端。以下描述当前实现，不代表端到端加密或完整删除功能已实现。

| 位置 | 保存的数据 | 生命周期与边界 |
| --- | --- | --- |
| Android | 配对身份、受保护的设备凭证、本地短信、同步队列、发件执行记录、SIM 映射 | 应用私有存储；短信未做应用层数据库加密；排除系统云备份和设备迁移。解绑与换后端不会自动向新后端迁移旧队列 |
| 服务器 SQLite | 短信正文、发件内容与状态、设备/SIM、管理员密码摘要、会话与设备凭证摘要、浏览器粗略描述、初次登录/最近前台访问时间、配对记录 | 当前不自动按天删除短信；宿主机及备份访问者可能读取内容。没有完整的网页数据清空/保留期管理 |
| 浏览器/PWA | HttpOnly 会话 Cookie；同会话近期短信、设备/SIM、发件视图快照 | 确认会话后恢复；快照最长 24 小时，磁盘收件最多 500 条；退出/401 清理。草稿、CSRF 和配对码不持久缓存 |
| Service Worker | 公共页面外壳与构建资源 | 仅静态白名单；不把私有 API 响应写入 Cache Storage |
| 推送 | 服务端 VAPID 私钥、浏览器 endpoint 与订阅密钥、待投递任务 | 主动开启，默认关闭；正文不进入推送，发件人会显示并可能出现在锁屏。推送经过浏览器厂商服务，使用 Web Push 加密 |
| 备份 | 数据库、会话/设备认证相关数据、推送身份 | 没有自动备份保留期；由部署者加密、限制权限、保留及删除 |

通知任务最多尝试一小时，完成/失败/过期记录七天后清理。关闭、退出、撤销或会话到期停止关联投递；已经被外部推送服务受理或已经显示的通知无法撤回。删除服务器记录不会删除手机原短信或旧备份。

应用日志不记录短信正文、密码、Cookie、设备凭证和推送订阅。部署者仍需检查代理、监控、诊断工具的日志策略。提交问题时只使用虚构数据，不要上传运行数据库、二维码、通知订阅或真实短信截图。

卸载 Android、清除浏览器数据或删除服务端卷是不同操作，不能互相代替。删除任何数据前先确认未同步短信和待执行命令，避免不可恢复丢失。完整保留期与账号恢复能力仍属于后续工作。
