## 本轮结果

- 后端 `npm test`：17/17通过。新增覆盖浏览器/设备鉴权隔离、Origin/CSRF、两个独立会话、旧消息独立增量、过时版本冲突、新收件默认未读、105条状态分页（分页间更新重新前移）、状态及版本时钟重启持久化。历史v1升级链到v5保留消息ID/归属/凭证并设为未读。
- Web `npm run typecheck`、`npm test`（17/17）、`npm run build:client`、`npm run test:sites`（4/4）通过。新增版本合并、未加载消息状态、后台/忙碌不消费可见机会、新消息、当前详情停留不反复自动标读、手动未读抑制和重新进入恢复的测试。
- 使用 Codex 内置浏览器与 Chrome 分别登录，实际生产构建接真实 API，无 demo 数据回退。A打开虚构测试乙后，B无需刷新即由14未读降至12；A标回未读后，B轮询恢复14。双方均停留乙详情时，A标回未读，B显示未读并保持，不发生自动互相覆盖。
- 长会话（12条）进入详情仅可见部分已读，屏幕外消息仍未读；列表加载本身不标读。手动未读保持到离开，重新进入触发自动标读。
- SIM订阅2过滤显示2条未读及1个会话；未读筛选后手动标读，会话从列表移除而详情保留。计数以当前范围已加载消息为准。
- 暂停独立测试服务模拟请求超时：显示“阅读状态未确认”反馈，保留上次已确认状态、正文和登录；恢复服务后正常刷新与手动更新。没有将失败显示成登录过期或成功保存。
- 360×800列表、390×844详情及1440×900双栏完成视觉检查。修正了长SIM标签重叠、消息元信息布局和手机底部导航遮挡详情；滚动视口现在止于底部导航上方。
