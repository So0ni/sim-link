## 五项视觉复核

- 字体：系统 sans-serif，标题 30px/700，正文 16px，辅助文字 12–14px。概念图桌面字形整体更大；实现遵循后续 token 建议，未模仿图片缩放产生的字号。验证码详情使用等宽数字；长摘要截断，原文保留。
- 间距与布局：桌面侧栏 192px、列表 380px，900px 宽时侧栏 72px/列表 360px，手机 20px 页边距、独立详情。列表比桌面概念图窄是后续 token 约束；不以生成图中约 510px 列宽替代。
- 颜色：直接读取仓库 JSON 的白色、primary、surfaceSelected、语义 warning 等颜色。列表选中与未读分别表达；离线和未知结果同时有文字说明。
- 资产：使用 Phosphor 的 SIM、信封、设备、设置、复制与用户图标，保持同一图标家族。无需外部照片/插画；字母头像和用户图标对应源设计中的身份标记。未把整张设计图作为页面。
- 文案：已发送和已送达严格区分；未知结果持续呈现，刷新只查询。补充清楚的演示标识；演示登录无需收集真实密码。列表中的 GitHub 也提供复制按钮，属于一致的验证码操作；正文与演示时间和概念图并非逐字相同。
